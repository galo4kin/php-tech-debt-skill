# PHP Tech Debt Skill

Скилл для Claude Code, который проводит аудит технического долга в PHP-проектах. Сочетает автоматический анализ инструментами с глубоким архитектурным аудитом и выдаёт детальный отчёт.

## Возможности

**Оценка здоровья проекта (0-100 баллов)** — запускает до 11 инструментов статического анализа и контроля качества (PHPStan, semgrep, phpcs, PHPUnit и другие) и оценивает проект по 5 категориям: Безопасность, Статический анализ, Зависимости, Качество кода и Покрытие тестами. Каждая категория — 20 баллов. Если каких-то инструментов нет, оценка нормализуется автоматически.

**Архитектурный аудит по 9 измерениям** — анализ на основе Claude, который ищет конкретные паттерны: god-классы, N+1 запросы, пустые catch-блоки, отсутствие strict_types, захардкоженные пароли и десятки других. Каждая находка содержит ссылку `файл:строка`.

**Отслеживание между запусками** — повторный запуск аудита показывает, что исправлено, что появилось нового и как изменился балл. Находки получают статусы: ACTIVE, RESOLVED, SHIFTED или NEW.

**Поддержка Docker** — автоматически обнаруживает PHP в контейнерах. Никакой настройки не нужно.
